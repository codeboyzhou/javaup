# Recording the terminal demo

The GIF in the repository README is generated by
[`demo.tape`](demo.tape) with [VHS](https://github.com/charmbracelet/vhs).
The recording uses the real `jup` executable, Maven, and two installed JDKs.

## Record with Docker

Docker is the recommended recording environment. The image builds the current
`jup` source, installs Maven, provides Temurin JDK 8 and JDK 17, and caches the
Maven plugins used by the demo before recording starts. It also installs the
LiterationMono Nerd Font selected by the tape.

From PowerShell, build the image and record the GIF with:

```powershell
.\docs\demo\record.ps1
```

When only the tape changed and the `javaup-demo` image already exists, skip
the image build:

```powershell
.\docs\demo\record.ps1 -SkipBuild
```

From Linux, macOS, Git Bash, or WSL, build and record with:

```shell
./docs/demo/record.sh
```

To reuse an existing image:

```shell
./docs/demo/record.sh --skip-build
```

The equivalent manual commands are:

```shell
docker build \
  --build-arg "JAVAUP_COMMIT=$(git rev-parse --verify HEAD)" \
  --file docs/demo/Dockerfile \
  --tag javaup-demo \
  .
docker run --rm --volume "$PWD:/jup" javaup-demo docs/demo/demo.tape
```

VHS writes the result directly to `docs/demo/demo.gif` in the mounted repository.
Temporary javaup configuration is stored under the ignored `.vhs/` directory.
Remove the recording image when it is no longer needed:

```shell
docker image rm javaup-demo
```
